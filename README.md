# Aarohi Ethnic Wear — local website preview

This is a small, self-contained website. It does not need Node, an account, or an internet connection to run locally.

## Open the website

1. Double-click **Start Website.bat**.
2. Keep the black command window open while you browse.
3. Open [http://localhost:8000](http://localhost:8000) in your browser.
4. To stop the local website, click the command window and press **Ctrl+C**.

You can also open `index.html` directly, but the local server gives the most reliable preview.

## What the preview can do

- Browse and filter the sample kurta sets, co-ord sets, embroidered suits and kidswear.
- Search styles, open product details and select a size.
- Add items to a bag; the bag is saved only in this browser on this computer.
- Walk through a demo checkout. It does not place an order, save the details or take payment.
- Explore the WhatsApp order buttons. Add Aarohi’s business number in `app.js` to connect them.

## Before a public launch

The product names, photos, descriptions and prices are sample content. Replace them with the real catalogue. Add the store’s WhatsApp number and customer email, and decide the size guide, shipping and returns information. Real online payments need to be connected to a payment provider account; the current checkout is only a preview. The newsletter form is also a visual preview and does not collect email addresses.

The source files are `index.html`, `styles.css` and `app.js`. Images used by the site are in `assets/`.
