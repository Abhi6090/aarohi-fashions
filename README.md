# Aarohi Fashions

Private source repository for the Aarohi Ethnic Wear storefront.

The site is a static HTML, CSS and JavaScript preview. Product names, images and prices are samples. Checkout is a demo and does not place orders or take payments.

For local instructions, see the README in the website folder. The production store still needs real product information, WhatsApp contact details, shipping and returns terms, and an online payment provider.
